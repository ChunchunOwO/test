# ECHO 创意工坊使用指南

本指南面向使用 ECHO Steam 版创意工坊的普通用户。当前支持主题、歌词场景、可视化预设、DSP / EQ 预设、音频插件接入配置和沙箱插件。

> 最重要的一点：在 Steam 中「订阅」只会下载内容，不会自动改变 ECHO。回到 ECHO 的「创意工坊 → 已装」并点「使用」，内容通过安全校验后才会生效。

## 普通用户全链路验收

在“创意工坊 → 编排中心 → 普通用户全链路验收”输入 Steam PublishedFileID，可以真实执行订阅、下载、内容校验、启用和运行态核验。开始前会再次确认；如果该项目原本没有订阅，验收结束后只移除这次新建的临时订阅，不会取消用户原有订阅。阶段结果会逐项显示，静态检查通过不能代替这里的 Steam 客户端实测。

项目声明必需依赖时，首次点“使用”会自动订阅缺少的依赖。等待 Steam 安装完成后再次点“使用”；ECHO 会继续检查版本范围和冲突，并按依赖拓扑显示建议加载顺序。

## 阅读导航

- 第一次使用：直接看「开始前检查」和「完整操作流程」。
- 不知道按钮作用：看「按钮说明」。
- 不知道内容是否生效：看「按内容类型确认效果」。
- 页面显示等待、错误或隔离：看「状态说明」和「按现象排查」。
- 想更新、停用或删除：看「更新、停用与取消订阅」。
- 想制作内容：跳到「给内容作者」。

## 开始前检查

使用创意工坊前，建议确认：

1. 安装的是 ECHO Steam 发行版，而不是另一个独立版本。
2. Steam 客户端已经登录，当前账号可以访问 ECHO 的创意工坊。
3. ECHO 是从 Steam 启动的，Steam 客户端没有完全退出。
4. Steam 下载设置没有暂停，磁盘上有足够空间。
5. 如果正在使用 Steam 离线模式，先恢复在线再浏览或同步工坊。

本功能不会要求 Steam 密码、Steam Guard 验证码或 Cookie。遇到要求提供这些信息的项目说明或第三方工具时，不要继续操作。

## 30 秒快速上手

1. 从 Steam 启动 ECHO，并确认 Steam 账号在线。
2. 打开 ECHO 左侧的「创意工坊」。
3. 进入「发现」，搜索或浏览想要的内容。
4. 点击「订阅」，等待 Steam 完成下载。
5. 回到「已装」，找到刚订阅的项目。
6. 点击「使用」。
7. 看到「已启用」或「当前主题」后即表示完成。

如果项目仍显示「等待下载」，先等待片刻并点击页面右上角的「刷新」。

## 页面认识

创意工坊页面分为四个主要区域：

- **发现**：查看 Steam 工坊目录、搜索内容、切换排序、订阅/退订、打开 Steam 项目页。
- **已装**：查看当前账号订阅并由 Steam 安装的内容，完成校验、导入、启用、应用、更新和停用。
- **创作**：新建或打开作者项目，用结构化表单或原始 JSON 编辑，切换本地模拟场景，查看发布前自检，保存并准备私有上传包。
- **编排**：查看依赖与冲突，创建自动化，回滚上一版本，清理失效版本，导入导出配置方案，并查看插件诊断。

页面顶部的运行状态用于判断链路是否正常：

- **Steam**：是否能读取当前账号的订阅和安装状态；
- **登记**：ECHO 是否能安全记录已校验项目和版本；
- **目录**：主题、歌词样式、可视化和 DSP 数据目录是否可写；
- **修复**：最近一次一致性检查是否完成。

如果「登记」或「目录」显示只读保护，ECHO 会停止写入，避免覆盖原有数据。此时不要反复点击使用，应先记录提示并重新启动 ECHO；仍未恢复再运行安全修复。

## 完整操作流程

### 第一步：发现内容

1. 打开「创意工坊 → 发现」。
2. 在搜索框输入标题或标签。按 `/` 或 `Ctrl+F` 可以快速聚焦搜索框。
3. 选择排序：
   - **趋势**：优先查看近期较活跃的项目；
   - **投票**：按社区投票浏览；
   - **最新**：优先查看最近更新的项目。
4. 查看预览图、简介、标签、项目号、点赞数和订阅数。
5. 不确定时点击「在 Steam 中查看」，阅读作者说明、更新记录与社区反馈。

预览图和介绍只能帮助判断内容方向，不代表项目一定兼容，也不代表其中所有素材已经获得合法授权。ECHO 会在真正使用前检查项目文件。

### 第二步：订阅并等待下载

1. 在项目卡片上点击「订阅」。
2. ECHO 会提示到「已装」列表继续操作。
3. Steam 开始下载项目；下载可能进入队列，并不一定立即完成。
4. 如果长时间没有变化，打开 Steam 的“下载”页面确认是否暂停、限速或缺少磁盘空间。
5. 下载完成后回到 ECHO 点击「刷新」。

不要为了催促下载而连续点击订阅/退订，也不要手工把其他目录伪装成 Steam 工坊安装目录。

### 第三步：使用内容

1. 切换到「已装」。
2. 可以按类型筛选主题、歌词样式、可视化、DSP、音频插件接入或沙箱插件，也可以按状态筛选待处理、已启用、已停用和异常。
3. 在搜索框输入内容 ID、项目号、类型或状态。搜索框获得焦点后可用上下方向键移动当前项目，按 Enter 执行主要操作。
4. 找到目标项目并点击「使用」。
5. 等待 ECHO 完成下载确认、清单检查、文件校验、导入、启用和应用。
6. 根据内容类型进入对应页面确认效果。

如果「使用」触发了下载，页面会提示“完成后会继续使用”。保持 ECHO 和 Steam 运行即可，不需要重复点击。

## 支持的内容

| 类型 | 能改变什么 | 使用后的表现 |
| --- | --- | --- |
| 主题 | ECHO 的颜色、布局、舞台和本地界面素材 | 显示「当前主题」时已经切换 |
| 歌词场景 | 歌词页的排版、动效和本地视觉素材 | 在兼容的歌词视图中生效 |
| 可视化预设 | 可视化器的参数与外观 | 启用后进入对应可视化查看 |
| DSP / EQ 预设 | ECHO Audio Core 支持的安全参数集合 | 启用并应用后由 Audio Core 执行 |
| 音频插件接入配置 | 描述用户本机安装的 VST3 效果器或 VST3i 音源、参数映射和便携预设 | 启用后登记配置；匹配插件与可选 Audio Core 适配器齐备后才可能实际处理声音 |
| 沙箱插件 | 增加命令、工具面板、可搜索音源、歌词源、Agent、曲库/播放列表/队列工具和音频可视化 | 确认权限后从界面右下角宿主「插件」入口使用；歌词源在歌词设置中使用 |

预设内容仍是声明式数据；只有明确标记为「插件包」的项目可以运行经过校验的 HTML/JavaScript，而且只在隔离 iframe 中运行。ECHO 不会从工坊内容运行程序、动态库、Node addon 或命令脚本。

## 按内容类型确认效果

### 主题

1. 点击「启用并切换」或「切换主题」。
2. 等待项目显示「当前主题」。
3. 检查主界面的颜色、侧栏、播放器、卡片和页面舞台是否变化。
4. 主题同时提供明暗模式时，可切换系统/ECHO 明暗模式确认两套配色。
5. 想恢复时，在 ECHO 主题设置中选择内置主题。

主题只能使用项目包内通过校验的本地素材，不能从任意网络地址动态加载图片或样式。

### 歌词样式

1. 点击「使用」。
2. 播放一首有歌词的本地歌曲并打开歌词页。
3. 打开歌词设置，在「创意工坊歌词主题」中直接选择该场景；也可以随时切回「ECHO 内置」。
4. 观察歌词布局、字号、行间距、舞台和受限动效。
5. 某些效果依赖当前歌曲确实有逐行歌词；无歌词或纯文本歌词时，视觉表现可能不同。

歌词样式不能携带字体程序、网页脚本、任意 CSS 或远程壁纸。

### 可视化预设

1. 点击「使用」。
2. 打开 ECHO 的可视化页面并开始播放音乐。
3. 确认颜色、灵敏度、运动和呈现参数是否符合项目说明。
4. 静音、暂停或音频能量很低时，画面变化可能不明显。

可视化项目只定义展示参数，不接管解码、播放或频谱事实。

### DSP / EQ 预设

1. 初次试听前先降低系统或 ECHO 音量，避免预设增益造成突然响度变化。
2. 点击「应用到 DSP」。
3. 播放一首熟悉的歌曲，确认均衡器或 DSP 控制面显示了对应参数。
4. 如果效果过强，立即降低音量并切回内置预设或手动设置。

DSP 参数最终由 ECHO Audio Core 执行。创意工坊页面只是控制面，不能自行生成或伪造音频后端状态。

### 音频插件接入配置

1. 先查看项目说明，确认它要求的插件厂商、名称、VST3 Class ID 和适配器最低版本。
2. 通过插件厂商的正规渠道自行安装并激活插件。工坊项目不会替你提供 DLL、安装器或许可证。
3. 在 ECHO 中点击「启用接入配置」。
4. 若列表仍提示需要本机插件或 Audio Core 适配器，这表示配置已经登记，但声音尚未经过插件；不要把“已启用”误解为“已处理”。
5. 效果器/音源真正可用后，仍以 Audio Core 报告的实例、旁路、延迟和故障状态为准。

接入配置中的 `0..1` 参数值是便携映射。不同版本的同名插件可能使用不同 Class ID 或参数 ID，遇到不匹配时应等待作者发布兼容配置，不要手改清单冒充兼容。

### 沙箱插件

1. 在「已装」找到插件包并点击「使用」。
2. 阅读权限确认框。重点留意播放控制、曲库修改、队列修改、直链音源、`network:request` 联网域名和 `playback:share` 上传权限；不理解时可以取消启用。
3. 启用成功后，点击 ECHO 界面右下角的「插件」入口。这里会显示作者声明的命令、面板、Agent、可搜索音源和插件设置。
4. **命令**：点击后立即执行作者定义的一次操作，例如整理队列或创建播放列表；执行失败会显示插件名和错误。
5. **面板**：在宿主持有的窗口中打开作者 UI。关闭按钮属于 ECHO，插件不能把它遮住。
6. **Agent**：输入任务并点击「运行 Agent」。它只能组合该插件已经获批的能力，ECHO 不会替作者提供模型账号或 API Key。
7. **可搜索音源**：打开提供器，输入搜索词，选择结果并点击播放。作者可以用已批准的 `network:request` 查询清单列出的远程目录；首次实际播放某个音频域名时，仍要核对来源确认框。
8. **插件设置**：从「插件 → 插件设置」调整作者声明的文本、数字、开关或选项。不要在普通设置里填写密码、Cookie、Token、Steam Guard 或 API Key。
9. **功能编排**：进入「插件 → 管理插件功能」，可以单独显示/隐藏、固定和排序命令、面板、Agent、歌词源、主题、歌曲菜单和播放器按钮，不必停用整个插件。
10. **页面位置**：作者可把面板入口放在侧栏、首页、歌词、队列、曲目详情或播放器附近；点击入口后仍在 ECHO 持有的隔离面板中打开。
11. **歌词源**：它不在右下角搜索面板中。播放歌曲后进入歌词页设置，在「创意工坊歌词源」里选择来源、查询候选，再对想用的歌词点击「应用」。
12. **一起听**：当插件请求分享当前本地歌曲时，ECHO 会显示歌曲和目标服务并逐次征求同意。上传前先确认作者写明了保存时间、删除方式和隐私规则。

插件启用后如果右下角没有「插件」入口，先确认项目状态为「已启用」，再等待几秒或刷新创意工坊页面。某个功能显示“正在加载”时，不要反复点击；若持续不恢复，停用插件并记录项目号、插件版本和错误信息。停用插件会移除它的命令、面板、Agent、音源和事件监听，但不会自动取消 Steam 订阅。

## 点击「使用」时会发生什么

在「已装」页找到项目后点击「使用」。ECHO 会依次完成：

1. 确认 Steam 已完整安装项目；
2. 读取 `echo.workshop.json` 内容清单；
3. 检查路径、文件类型、大小和 SHA-256；
4. 拒绝链接、可执行内容、远程资源和超出限制的文件；
5. 把通过校验的数据登记到 ECHO；
6. 启用并应用对应内容。

因此，「订阅成功」和「已经在 ECHO 中生效」是两个不同状态。

## 按钮说明

| 按钮 | 什么时候出现 | 实际作用 | 不会做什么 |
| --- | --- | --- | --- |
| 订阅 | 发现页未订阅项目 | 通知 Steam 订阅并安排下载 | 不会自动启用或应用 |
| 退订 | 发现页已订阅项目 | 取消 Steam 订阅 | 不等于立刻删除 ECHO 的安全登记 |
| 使用 | 已下载但未导入/未启用 | 尝试完成下载、校验、导入、启用和应用 | 不会绕过失败的安全检查 |
| 更新并继续使用 | Steam 报告存在新版本 | 下载/校验新版本并继续使用 | 不会直接信任作者更新 |
| 同步已安装版本 | Steam 本地已有可读取版本 | 重新校验并导入当前安装版本 | 不会自动启用已停用项目 |
| 启用并切换 | 已导入但停用的主题 | 启用主题并切换为当前主题 | 不会删除原主题数据 |
| 切换主题 | 已启用但不是当前主题 | 把该主题设为当前主题 | 不会取消订阅其他主题 |
| 应用到 DSP | 已启用 DSP / EQ 项目 | 通过既有 DSP 桥接应用安全参数 | 不会让 renderer 直接处理音频 |
| 启用接入配置 | 已导入但停用的音频插件配置 | 登记插件身份、参数映射和预设 | 不会下载、安装或直接加载 VST DLL，也不代表处理已生效 |
| 停用 | 已启用项目 | 停止在 ECHO 中使用 | 不会取消订阅或删除 Steam 文件 |
| 重新验证 | 隔离或错误项目仍有本地文件 | 再次检查清单和文件 | 不会强制放行不安全内容 |
| 重新下载 | 项目缺少可用本地文件 | 请求 Steam 重新取得内容 | 不保证网络或 Steam 队列立即完成 |
| 刷新 | 页面右上角 | 重新读取 Steam、登记和目录状态 | 不会修改内容文件 |
| 安全修复 | 页面右上角 | 核对并修复可安全恢复的登记关系 | 不会改写作者文件或绕过隔离 |

## 状态说明

| 页面状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 等待下载 | Steam 尚未完成下载 | 等待后点「刷新」 |
| 下载中 | Steam 正在传输项目文件 | 保持 Steam 在线，等待完成 |
| 等待导入 | 文件已下载，但尚未登记到 ECHO | 点击「使用」 |
| 已检测 | ECHO 已找到项目，正在进入校验/导入流程 | 等待操作完成 |
| 已验证 | 清单和文件检查已通过 | 等待安全登记完成 |
| 待恢复 | 上次导入在安全阶段中断，可由一致性修复恢复 | 运行「安全修复」 |
| 已停用 | 内容已经导入，但当前未启用 | 点击「使用」或「启用」 |
| 已启用 | 内容已经进入 ECHO 的可用目录 | 需要时点击应用或切换 |
| 当前主题 | 这个工坊主题正在使用 | 无需继续操作 |
| 有更新 | Steam 上存在较新版本 | 等下载完成后同步或重新使用 |
| 已隔离 | 项目没有通过校验或兼容性检查 | 查看错误；修正来源后重新验证 |
| 错误 | 下载、清单、文件或本地登记存在问题 | 先刷新，再按提示重新验证/下载 |

## 更新内容

Steam 通常会自动下载已订阅项目的更新。更新完成后：

1. 在 ECHO 创意工坊页面点击「刷新」；
2. 找到标记为有更新的项目；
3. 点击「同步已安装版本」，或再次点击「使用」；
4. 确认项目重新显示为已启用或当前使用状态。

更新仍会重新经过完整安全校验，旧版本不会因为 Steam 开始下载就被立即覆盖到 ECHO 中。

更新插件时，确认框会列出版本变化、新增/移除能力和贡献项数量变化。ECHO 保留上一可用版本；在「编排 → 更新、回滚与清理」选择回滚后，项目会回到停用状态，需要重新检查并启用。清理操作先展示候选数量和预计空间，只删除登记表不再引用的版本以及超过一天的暂存目录。

## 自动化、诊断与配置方案

在「编排」页可以把插件命令或 Agent 绑定到歌曲开始、Audio Core 确认歌曲结束、队列变化/清空、输出设备变化和定时器。规则可以逐条启停或删除；歌曲结束不会根据进度条猜测，只响应宿主发出的真实 `ended` 状态。

诊断区域记录插件加载、功能注册、命令、Agent、宿主调用和自动化耗时，便于作者定位“未注册、超时、调用失败”等问题。配置方案可以导出/导入插件声明设置、功能显示/固定/排序以及自动化规则；插件私有缓存和任意文件不会进入方案。导入到新版插件时只迁移仍然存在的设置项，缺少的插件会列为未应用。

## 停用、切换与取消订阅

- **停用**：让项目停止在 ECHO 中生效，但保留 Steam 订阅和本地下载。
- **切换**：对主题等互斥内容，选择另一个项目并点击「切换」或「使用」。
- **取消订阅**：由 Steam 取消后续更新并管理已下载文件；回到 ECHO 后点击「刷新」同步状态。
- **恢复内置主题**：在 ECHO 的主题设置中选择一个内置主题。

如果只是暂时不用，优先选择「停用」；如果以后也不需要，再取消订阅。

### 推荐的更新步骤

1. 先结束正在进行的主题切换或 DSP 调整。
2. 等 Steam 下载页面显示项目更新完成。
3. 回到 ECHO 点击「刷新」。
4. 点击「更新并继续使用」；如果只想校验但暂不启用，选择「同步已安装版本」。
5. 确认版本号、状态和实际效果。
6. 如果新版本表现不符合预期，先停用并切回内置内容，再向作者反馈。

### 推荐的移除步骤

1. 当前正在使用的主题先切回内置主题；DSP 预设先切回安全的内置/手动设置。
2. 点击「停用」。
3. 到「发现」点击「退订」，或在 Steam 项目页取消订阅。
4. 等 Steam 完成文件处理后回 ECHO 点击「刷新」。
5. 状态残留时运行一次「安全修复」。

## 安全修复会做什么

「安全修复」会重新核对 Steam 订阅、已安装内容、ECHO 登记和可用目录之间的关系。它不会修改工坊作者的原文件，也不会绕过失败的安全校验。

适合在以下情况使用：

- Steam 已下载，但 ECHO 长时间仍显示等待；
- 更新后状态没有同步；
- 项目被删除或取消订阅后仍残留旧状态；
- 页面明确显示「需要处理」或登记不一致。

## 常见问题

### 按现象排查

| 现象 | 先检查 | 然后尝试 | 仍未解决时记录 |
| --- | --- | --- | --- |
| 发现页为空或不可用 | Steam 是否登录、在线，ECHO 是否从 Steam 启动 | 刷新；重启 Steam 后再启动 ECHO | Steam 状态和页面提示 |
| 订阅后一直等待下载 | Steam 下载队列、暂停、限速、磁盘空间 | 恢复下载，完成后刷新 | 项目号和 Steam 下载状态 |
| 已下载但等待导入 | 已装页是否能看到项目 | 点击「使用」 | 项目号、版本和错误码 |
| 项目显示已隔离 | 作者包是否刚更新，文件是否完整 | 等 Steam 校验/重下后点「重新验证」 | 项目号和 ECHO 错误码 |
| 登记/目录只读保护 | 磁盘权限、文件是否被其他程序占用 | 重启 ECHO；再运行安全修复 | 页面状态，不要公开完整本地路径 |
| 主题已启用但外观没变 | 是否显示「当前主题」 | 点击「切换主题」 | 主题名、项目号和截图 |
| DSP 已启用但听不出变化 | 是否点击「应用到 DSP」、音频是否正在播放 | 用熟悉歌曲低音量对比，检查 DSP 控制面 | 项目号和参数截图 |
| 音频插件配置已启用但未生效 | 本机插件 Class ID、适配器版本和 Audio Core 状态 | 正规安装匹配插件；安装兼容适配器后重启并刷新 | 项目号、Class ID、适配器状态；不要发送许可证或序列号 |

### 看不到「发现」内容

确认 ECHO 是从 Steam 启动、Steam 已登录且在线，然后点击「刷新」。如果 Steam 正在离线模式，工坊浏览和订阅查询可能不可用。

### 已经订阅，但「已装」里没有

先检查 Steam 下载队列。下载完成后回到 ECHO 点击「刷新」。不要通过手工复制文件冒充 Steam 安装目录。

### 点「使用」后提示校验失败

项目的清单、哈希、文件类型或资源引用可能不符合 ECHO 的安全规则。先尝试刷新和安全修复；问题持续时，在 Steam 项目页向作者反馈错误信息和项目号。

请勿公开发送账号、Steam 票据、本地文件路径或包含个人曲库信息的完整日志。

### 取消订阅后界面仍显示项目

点击「刷新」或「安全修复」。ECHO 会保守地核对本地状态，避免在 Steam 状态暂时不可用时误删登记。

### 使用主题后想恢复

进入 ECHO 主题设置选择内置主题，然后按需停用或取消订阅原工坊主题。

### 页面提示项目不兼容

项目可能要求更高版本的 ECHO、不同清单版本或尚未开放的能力。先更新 ECHO；如果仍不兼容，不要手改清单绕过限制，等待作者发布兼容版本。

### 工坊插件可以做什么

工坊插件可以用 JavaScript 增加命令、工具面板、可搜索音源提供器、可选择的歌词源和作者自己编写的 Agent，浏览曲目、专辑、艺人和流派，操作收藏与本地播放列表，编排当前播放队列，打开 ECHO 页面，或使用 Audio Core 提供的只读频谱制作可视化。获得 `sources:provide` 权限的插件会在宿主插件入口提供自己的音源搜索界面；作者代码负责返回候选并把选中项解析为直链，ECHO 负责校验、来源确认、队列与实际播放。获得 `sources:direct` 权限的面板也可以直接请求播放 HTTP(S) 直链音源；ECHO 会在当前会话第一次使用某个来源域名时再次显示插件名和来源，让你确认后才交给现有播放队列。获得 `network:request` 权限的插件可以通过宿主向清单列出的固定域名发送有超时和大小上限的 GET/POST 请求，用于远程歌词目录、网络音源目录、Webhook 或作者自有 Agent 服务。

申请 `lyrics:provide` 的插件会出现在歌词设置的「创意工坊歌词源」中。只有你选择某个源并点击查询时，ECHO 才会把当前歌曲的标题、艺人、专辑和时长交给它；不会提供本地文件路径或音频内容。插件返回的歌词会先显示为候选，只有你再次点击应用后才会替换当前歌词。此能力本身不包含网络访问；作者若同时申请 `network:request`，可把这些清理后的字段发往确认框列出的歌词服务域名。

所有能力都要逐项声明并由你明确批准。Agent 是工坊作者提供的逻辑，ECHO 不会替作者提供统一模型或 API Key；它只能组合该插件已经获批的宿主工具。`network:request` 也不是任意浏览器 `fetch`：它只能访问清单列出的域名，只支持受限 GET/POST，不携带 Cookie、Steam 身份、本地路径或自动凭据，并限制请求大小、响应大小、超时、跳转和并发。插件只在隔离 iframe 中运行，不会直接从 Steam 安装目录执行，也拿不到 Node、DLL、任意文件、Steamworks、原始 IPC 或音频宿主对象。插件第一次启用，以及更新后权限或联网域名发生变化时，ECHO 都会再次显示精确清单让你确认。

插件还可以声明自己的设置项。ECHO 会用宿主界面统一显示文本、数字、开关和选项设置，并按插件隔离保存；作者代码可通过 `echo.settings` 读取、修改和监听变化。这些值不会写入 ECHO 全局设置。Workshop 不接受密码或 API Key 类型的设置项，不要把凭据填入普通文本设置。

如果插件申请 `playback:share`，它是在制作“一起听”之类的功能。启用确认框会列出插件声明的上传/CDN 域名；真正上传当前本地歌曲前，ECHO 还会逐次显示歌曲标题和目的地，让你再次确认。插件本身看不到本地路径或文件，只能读取上传进度和服务返回的播放 URL。上传意味着音频会离开你的电脑，请只向可信服务分享你有权传输的内容，并查看作者写明的保存与删除规则。

### 可以同时使用多个项目吗

可以同时订阅和导入多个项目，但同一时刻的“当前主题”等互斥位置通常只有一个。歌词样式、可视化和 DSP 也以各自页面当前选择/应用状态为准。

## 安全、隐私与反馈

- ECHO 只从 Steamworks 支持的订阅链路读取工坊项目，不要求用户导入 Steam 凭据。
- 工坊内容必须声明本地文件、精确大小和 SHA-256；未声明文件不会被当作可信内容使用。
- 路径穿越、符号链接、远程 URL、网页脚本、命令文件、可执行文件和原生模块会被拒绝。
- 订阅或下载不会自动启用，防止作者更新在未确认时直接改变 ECHO。
- ECHO 不会因为工坊项目而上传本地曲库路径、文件名、歌词、封面、播放记录或设备列表。
- 反馈问题时，优先提供项目号、ECHO 版本、项目版本、页面状态和错误码。
- 截图前遮挡账号名、通知、私有路径和本地曲库内容；不要发送 Steam 票据、Cookie、密码或 Steam Guard 验证码。

## 一次完整示例：安装并切换主题

假设你想使用名为 “Midnight Record Room” 的主题：

1. 从 Steam 启动 ECHO。
2. 打开「创意工坊 → 发现」。
3. 搜索 `Midnight Record Room`，核对标题、预览、Theme 标签和项目号 `3783131921`。
4. 点击「订阅」。
5. ECHO 返回「已装」后，如果显示等待下载，就查看 Steam 下载队列。
6. 下载完成后回到 ECHO 点击「刷新」。
7. 点击项目的「使用」；如果已经导入但停用，则点击「启用并切换」。
8. 等待提示完成，并确认项目显示「当前主题」。
9. 浏览首页、歌曲列表、歌词页和播放器，确认布局与配色正常。
10. 如果不喜欢，进入主题设置切回内置主题，再停用或退订该项目。

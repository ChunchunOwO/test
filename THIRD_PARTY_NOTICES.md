# ECHO Steam - Third-Party Components and Notices

Last reviewed: 2026-08-06. This inventory covers components intentionally included in the Steam Windows distribution (app resources, native host, production Node packages, Electron runtime, and bundled fonts), plus licensed datasets fetched by an enabled product feature. `package-lock.json` is the version lock for transitive npm packages; a Steam release must be built from this lockfile and must retain the applicable package license texts in the final artifact.

## Release gate

Do not publish a Steam depot build until the licensing owner records the applicable source/notice obligations for every transitive package and resolves the two explicit blockers below:

1. The selected FFmpeg binary and native-host DLLs must be prepared from the same pinned BtbN `LGPL` shared archive and pass the GPL/nonfree configuration gate. Preserve its LGPL text and corresponding-source URL with the final package.
2. The ASIO SDK is usable only under GPLv3 or a signed proprietary Steinberg ASIO SDK agreement. The agreement is not stored in this repository; do not claim a proprietary redistribution right until it is supplied and recorded.

This file is a technical inventory, not a legal opinion. It intentionally records uncertainty instead of treating a successful build as a license clearance.

## Maintenance procedure

1. Update this file, `package-lock.json`, and any copied notice text together whenever a shipped dependency/resource changes.
2. Run `npm run check:third-party-notices` and `npm run check:steam-distribution` before a release build.
3. For a final Windows artifact, verify `resources`, `app.asar`, and `app.asar.unpacked` contain this file and all required upstream notices. Record the build commit, artifact hashes, and an exported component list with the release evidence.
4. Do not add third-party images, media, fonts, SDKs, or binaries without adding their upstream URL, version/commit, license, modification status, and commercial-redistribution status here.
